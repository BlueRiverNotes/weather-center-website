# OpenSky Weather Center — Public Website

A public weather information website for current conditions, forecasts, radar, and severe-weather information.

## Planned features
- Current conditions and forecasts
- National and regional radar
- Official watches, warnings, and advisories
- State and regional weather pages
- Tropical weather information
- Travel weather information
- Mobile-friendly design

## Weather information standards
- Identify the authoritative source for official weather products.
- Display issue, effective, and expiration times when available.
- Distinguish official alerts from OpenSky summaries and commentary.
- Do not present expired alerts as active.
- Show the time of the latest successful data update.
- Clearly identify missing, delayed, or unavailable data.

## Project status
This repository is the public-facing website project. The website is under development; no live weather feature is claimed to be operational yet.

## Security
Never put API keys, passwords, private tokens, backend credentials, or internal administrative code in this public repository. Anything published here should be treated as publicly accessible.
