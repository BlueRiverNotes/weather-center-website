# OpenSky Weather Center

A nationwide public weather-information platform covering severe weather, radar, official alerts, outlooks, forecasts, satellite imagery, tropical weather, winter weather, fire weather, observations, and storm reports across the United States.

## Public experience
- National dashboard
- Live radar and storm analysis
- Tornadoes and severe thunderstorms
- Flooding and excessive rainfall
- Tropical weather
- Winter weather
- Fire weather
- Extreme heat and cold
- Satellite imagery
- Forecast guidance and soundings
- Lightning, observations, and storm reports
- National outlooks and forecast discussions

Nationwide coverage includes all 50 states and Washington, D.C.; U.S. territories are included where supported by official data.

## Shared weather engine
The public website and OpenSky ChatGPT integration are designed to use the same server-side weather services. This repository contains public-facing code and documentation only. Backend credentials, private processing, and administrative functions must remain outside this public repository.

## Data integrity
Official alerts, outlooks, discussions, forecasts, observations, radar products, and OpenSky summaries are distinct. Displayed products should identify their source, issue/validity times, retrieval/update time, and authoritative link. Expired, stale, canceled, or unavailable information must never be presented as current active information.

## Current status
The initial responsive website shell is under development. Status indicators are intentionally marked as not connected until a backend and verified live feeds are deployed. No live weather or radar feed is claimed operational yet.

## Security
Never commit API keys, passwords, private tokens, backend credentials, or internal administrative code to this public repository.
